# Model and data licences

Every model, voice, wake-word asset and dataset must be recorded here with the
version checked, the licence, the source URL, the date checked, and whether
redistribution is allowed. Downloading something for local personal use is not
permission to redistribute it or bundle it in an installer.

## Language model

No pretrained language model is used or bundled. The current transformer is
initialized randomly and must be trained on owner-supplied data. Its tokenizer
and checkpoint inherit the licences and permitted uses of that training data;
track each source in `brain-lab/data/manifests/`.

## Optional speech output

ClaireAI can call a separately installed eSpeak NG executable for offline text
to speech. This repository does not bundle its executable or voice data, so the
version is the host package version rather than a pinned dependency. Upstream
identifies GPL-3.0 among the project licences. The app sends text through stdin
and receives WAV data through stdout before passing it to the system audio
player. See the [upstream project](https://github.com/espeak-ng/espeak-ng) and
[command-line documentation](https://github.com/espeak-ng/espeak-ng/blob/master/src/espeak-ng.1.ronn).

If eSpeak NG or a compatible system audio player is absent, speech preview
reports that condition; text chat remains available. This is basic synthetic
speech, not a custom-trained voice. Speech recognition and wake-word support
remain unselected.

## Training data (`brain-lab/`)

`brain-lab/data/bootstrap-v1/` is an original, deterministic, MIT-licensed
synthetic corpus generated by `brain-lab/build_dataset.py`. It contains text
examples for safe read-only tool routing, approval behavior and factual reports,
plus 80 generated SVG workspace images with grounding annotations. No third-
party assets, scraped text or user content are included. Train/validation/test
splits are separate; training does not read the test split. The current model
uses the text/accessibility descriptions only; the images are paired data for
the next vision-model stage, not evidence of current visual capability.

`brain-lab/data/external/gui-primitives/` is a local-only supplemental image
corpus fetched by `brain-lab/fetch_gui_images.py` from the pinned
[GUI-Primitives dataset](https://huggingface.co/datasets/kagnlp/gui-primitives)
revision. It downloads only that project’s synthetic screenshots and filters
annotations to those images; real UI-Vision screenshots are excluded. The
upstream card applies CC BY 4.0 to its own synthetic content;
the downloader records attribution, source revision and per-file SHA-256 hashes.
Machine-generated pool examples are split by image, and images shared with its
human-verified clean split are withheld from training. That clean split is kept
for evaluation. The raw download is git-ignored. The current model does not yet
consume pixels, so these online images are staged for the vision-training slice
and are not fed to the text-only trainer.

Any later external dataset must have its source, licence, retrieval date, size,
and processing steps recorded in `brain-lab/data/manifests/` before use. Raw
downloads and user data remain git-ignored.

task saves one, the saved file is the owner's data and follows the same rules as
any other file ClaireAI writes.
